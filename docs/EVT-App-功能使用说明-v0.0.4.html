02

查找并连接设备

先查找，再选中，最后连接。扫描列表出现设备不等于认证成功。

  1. 打开手机蓝牙，让目标 EVT 设备靠近手机并处于可连接状态。
  2. 点击“查找附近设备”，按系统要求允许权限。
  3. 核对设备名称，点击目标设备行，再点底部“连接设备”。
  4. 等待连接与 GATT 检查完成，进入设备详情后进行安全码认证。
点击 / 操作前提或位置预期效果
查找附近设备连接设备页开始扫描，按钮变为“停止查找”；列表陆续显示有名称的 BLE 设备。
设备行扫描结果列表选中该设备；名称、信号描述和 RSSI 帮助核对目标。RSSI 是信号强度，越接近 0 通常越强。
停止查找扫描中停止继续扫描；不是断开已建立的设备会话。
连接设备已选中设备显示“正在连接”；成功后进入设备流程，失败提示检查设备状态并重试。
重新查找扫描错误提示区重新尝试扫描；先处理蓝牙开关、权限、定位服务等提示。
开启蓝牙 / 我已开启蓝牙关闭提示Android 可弹出系统开启确认；iPhone 需手动打开蓝牙后点“我已开启”。
Android 12 及以上需要“附近设备”权限；Android 6–11 还需定位权限与系统定位服务。EVT 当前会展示所有有名称的 BLE 设备，请选对目标；真正连接时才校验 EVT GATT 合约。
03

认证与首次绑定

安全码线上始终是 6 字节；输入文本时由 App 完成编码。

点击 / 操作前提或位置预期效果
认证设备 → 开始认证已绑定设备；已连接输入当前设备安全码。成功显示“设备认证完成”，设备详情显示“已认证”并开放获准的业务操作。
首次绑定设备 → 确认绑定未绑定的新设备输入待绑定安全码并提交，在 60 秒内短按设备按键。设备确认后 App 自动完成本次连接认证。
显示 / 隐藏安全码输入框右侧查看或遮蔽已输入内容，不改变实际下发的安全码。
取消安全码弹层关闭输入弹层，不提交认证或绑定命令。
输入不足 / 格式不符安全码输入框显示格式提示，确认按钮不可点击。6 位文本区分大小写，不接受空格或中文。
输入方式示例输入实际内容
6 位文本12345631 32 33 34 35 36（6 字节）
12 位十六进制31323334353631 32 33 34 35 36（同样 6 字节）
12 位表示不是 12 字节7A31C85E92B47A 31 C8 5E 92 B4；仅为格式示例
以上安全码只是编码示例，不是所有设备通用密码；请使用固件当前认可的安全码。此 EVT 构建尚未接入云端取码服务。
新连接认证后，App 自动同步手机时间及 EVT 基线录音参数（1800 秒、模式 1、类型 2、降噪关闭、实时音频关闭）。这些参数当前不是设置页的可编辑项；断连后重新连接需要重新认证。
04

控制吊坠录音

此处控制设备端录音。先开启录音授权，再执行开始、暂停、继续和结束。

点击 / 操作前提或位置预期效果
允许设备录音认证完成且具有配置权限写入设备录音授权并回读。开启后显示“已允许”；关闭时不能开始或继续录音。
开始录音已认证、有控制权限、已授权、非隐私模式下发设备录音命令。收到有效设备状态后显示正在录音，并出现暂停与结束按钮。
暂停录音设备正在录音下发暂停命令。状态变“已暂停”，按钮变“继续录音”。
继续录音设备已暂停、授权有效、非隐私模式恢复设备录音；状态回到“正在录音”。
结束录音设备正在录音或已暂停停止本次录音。成功后显示未在录音，再去设备文件页刷新，等待设备完成文件封装。
命令执行中点击控制按钮后显示进度指示并禁用重复操作，等待设备响应。
刷新状态提示失败或状态与实物不一致重新读取设备录音状态；用于回包丢失后的核对，不会自动重发开始 / 暂停 / 结束命令。
隐私模式下不能开始或继续录音，请在设备端退出隐私模式。按钮点击成功、命令发出和设备确已录音是不同阶段，最终以设备状态与录音文件为准。
05

查看设备状态与配置

展示设备返回的读数；“暂未读取”和“暂时无法获取”都不代表数值为零。

点击 / 操作前提或位置预期效果
刷新状态设备状态卡片右上角按当前认证权限读取录音状态、身份、电量、存储、设备状态、时间、隐私时长和可选文件数。
默认隐私时长设备状态卡片底部可选“手动退出 / 10 分钟 / 30 分钟 / 60 分钟”，保存后显示回读值。
设备检查设备详情下部进入场景验证页面，整理当前快照和已有协议事件证据。
显示项页面内容如何理解
设备录音状态未在录音 / 正在录音 / 已暂停来源为设备状态响应；错误或无法识别状态显示“暂时无法获取”。
电量百分比，可能标注充电中电池读数，不是手机电量。
存储空间剩余 / 总容量，MB设备存储，不是手机剩余空间。
文件数量（上次）最近一次读取的文件数是缓存读数；新录音封装后需刷新。文件列表页才展示具体文件。
隐私状态关闭 / 剩余分钟 / 手动退出实际进入和退出隐私由设备端操作。
同步状态空闲 / 同步中 / 录音暂停同步 / 同步失败来自设备，与手机端下载百分比不是同一字段。
设备编号 / 固件版本 / 状态采样时间身份与采样时刻用于核对设备和状态的新旧；未读取时不补造结果。
06

设备文件：下载到手机

“保存到 App”就是下载。完成后可直接播放，也可进入已保存录音。

  1. 结束设备录音，等待设备完成文件封装。
  2. 打开“设备录音文件”，必要时点击“刷新”。
  3. 找到目标文件，点击“保存到 App”，等待进度完成。
  4. 出现“已保存到手机”后点“播放”，或进入“已保存录音”。
点击 / 操作前提或位置预期效果
进入设备录音文件连接、认证完成且具有文件权限自动分页读取设备文件列表；空列表显示无文件提示。
刷新当前没有下载任务重新读取完整设备文件列表；下载中禁用刷新和其他文件的保存操作。
保存到 App选择一条设备文件接收设备文件，校验连续偏移、声明长度与结束帧，完成后保存到本地库。
播放本次保存成功的文件直接进入该文件播放器；此入口只有单条文件，上一条 / 下一条不可用。
已保存录音设备文件页右上角打开手机录音库；删除本地文件后返回，本页恢复“保存到 App”，可重新下载。
断线后再次保存重新连接并认证同一设备同一文件可使用已保存断点续传；设备声明大小改变时重新下载。
当前没有批量下载、手动取消、设备文件删除或归档按钮。返回上一页不等于取消正在执行的下载。下载仅产生手机副本，设备原文件仍保留。
07

管理已保存录音

这里管理手机里的副本，设备未连接也能使用。

点击 / 操作前提或位置预期效果
播放 / 点击录音条目已保存录音列表打开本地播放器。支持的格式可播放，未支持格式显示原因。
管理 → 重命名 → 保存录音行右侧只更改手机列表中的标题；标题不能为空，最多输入 60 个字符，不改设备文件名。
管理 → 删除 → 删除录音行右侧删除手机录音及本地记录，列表移除该项；设备原文件保留。取消则不删除。
重试读取本地库失败时重新加载录音库。读取失败会明确提示，不再误显示“暂无已保存录音”。
“保存于”是下载到手机的时间，不是设备录音开始时间。列表中的时长来自本地记录，可能仍显示未知；播放器识别出的真实时长目前不会回写列表。
08

播放与进度条

进入页面先读取文件，不自动播放；进度以播放器真实位置为准。

点击 / 操作前提或位置预期效果
播放录音加载完成后开始或继续播放手机文件；按钮变“暂停录音”。这里的“录音”指音频文件，不会启动吊坠录音。
暂停录音播放器正在播放暂停本地音频并保留当前位置，再点“播放录音”继续。
拖动进度条已读取有效总时长拖到目标时间，松手后定位；显示目标位置。总时长未知或加载中时不可拖动。
上一条 / 下一条从录音库进入且前后有录音按录音库顺序切换；第一条的上一条、最后一条的下一条禁用。切换后重新加载。
播放结束后再点播放录音完整播放结束从 00:00 重新播放。
加载失败后点播放录音出现加载失败提示重新尝试加载文件；持续失败时检查文件是否完整、格式是否受支持。
返回离开播放页释放当前页面的播放器资源，返回来源页面。
图中示例总时长 00:20、位置 00:08，显示进度 40%。Android 可播放设备 OGG/Opus；iOS 当前可下载 OGG，但不支持通过本构建播放它，需 M4A/AAC 或另行增加解码支持。

日志查看与导出

联调异常时先导出日志，便于同时核对 App 操作与固件事件。

点击 / 操作前提或位置预期效果
暂停跟随实时日志页冻结当前屏幕显示，后台仍持续记录，不暂停 BLE 通信。
继续跟随已暂停显示时立即补齐暂停期间的新日志，继续跟随最新内容。
清空视图实时日志页清空当前显示条目，不删除已写入的日志文件。
导出日志Debug 联调构建先写完待保存日志，再生成带秒级时间戳的独立副本；执行中显示“正在导出”，完成提示保存路径。
到手机文件管理器查找导出完成后进入提示中的 AIPIN/logs 目录。当前按钮保存文件，不弹出系统分享选择器。
平台 / 情况位置文件名示例
Android 10 及以上Download/AIPIN/logs/aipin-2026-09-15-17-27-08.log.txt

日志持久化只用于 Debug 联调构建。日志可能含原始协议字节，包括安全码、文件名或音频内容；对外提供前请检查。
10

断开、回连与解绑

临时断开连接和清除设备绑定是两种不同操作。

点击 / 操作前提或位置预期效果
断开设备 → 断开设备设备详情下部确认后断开 BLE，本轮不立即自动回连；不会删除录音或解绑。
重新连接断开或异常状态重新尝试连接设备。连接恢复后重新输入安全码认证。
非主动断线App 在前台且已有记忆设备尝试自动回连同一设备；进入后台停止扫描和回连。回连后仍需重新认证。
设备管理 → 解绑设备 → 继续解绑已认证，录音停止，同步空闲，设备文件列表为空继续输入设备安全码。成功后设备清除绑定与用户配置，App 断开并清除记忆连接和该设备的下载断点。
恢复解绑前一次解绑已经下发但结果未确认重新连接后使用原设备同一安全码恢复，最长等待 120 秒。仅在待恢复状态显示此入口。
取消断开或解绑确认弹窗关闭确认弹窗，不继续执行相应操作。
有设备录音文件时，当前 EVT 会阻止普通解绑。下载到手机不会让设备文件列表变空；本构建没有设备文件归档 / 删除功能，需由固件联调流程处理后再解绑。解绑不能作为日常“断开”使用。
11

设备检查与人工观察

选择场景后查看已有证据和缺失项，再保存结果。不是一键执行整套硬件测试。

点击 / 操作前提或位置预期效果
设备检查已认证可用的设备详情打开“验证场景”，使用进入时的设备快照和已有事件。
场景选项验证场景页上方切换判断规则，展示当前证据能否支持该场景。选择本身不会触发设备动作。
保存验证结果非物理反馈场景保存结论、原因、快照与来源事件；成功显示“已保存”。存储失败显示“保存失败，请重试。”
物理反馈 → 记录人工观察人工反馈场景打开“记录观察”；选择标签、填写备注，文字非空时可保存。
LED / 按键 / 异常记录观察弹层给人工备注添加分类标签，不会控制 LED 或替用户点击设备按键。
保存填写观察备注后保存人工观察与当前快照。失败保留输入，可再次点击保存。
场景依据结果边界
设备访问可读取的最终设备状态用于核对是否获得可用状态，不代表全部功能通过。
VAD 录音录音开始、静音结束的顺序事件及最终待机缺少完整事件链时不能据此判定 VAD 正常。
电池与充电电量百分比、充电状态验证证据是否存在，不测试电池容量或充电曲线。
待机功耗待机功耗测量值当前 EVT 链路没有提供该测量值时会不可验证，仍需外部仪表。
恢复验证恢复前后状态当前页面以传入快照判断，不主动重启设备或执行恢复实验。
物理反馈用户填写的观察备注依赖人工观察，保存记录不代表自动检测硬件通过。
页面不是持续采样仪表。若设备状态变化后需重新评估，先返回设备详情刷新，再进入检查页。缺少证据时请如实保留不可验证结果。
12

查看检查记录

保存的结论与原因在这里回看，录音和协议日志各有单独入口。

点击 / 操作前提或位置预期效果
检查记录底部导航读取本地已保存的检查条目；没有记录时显示“暂无检查记录”。
通过 / 未通过 / 证据不足每条记录右侧对应保存时的判断，不会随设备当前状态自动改写。
原因 / 备注 / 时间每条记录文字区用于还原检查结论和人工观察；带“模拟数据”标识的记录属于测试数据。
重试检查记录读取失败时重新加载本地检查记录，失败不会误显示为没有记录。
首页底部导航返回设备、文件、日志等操作入口。
当前底部检查记录页面用于查看，未提供该页面的详情、删除或导出按钮。代码中其他未接入当前入口的历史组件，不计入本使用说明。

设置与权限

联调问题快速定位

先确认前提，再核对设备读数，最后导出同一时段日志。

现象先检查下一步
已给蓝牙权限仍不能扫描Android 版本、附近设备或定位权限、定位服务、系统蓝牙开关回到设置核对后重新查找；Android 6–11 仅打开蓝牙并不够。
列表有设备但连接失败是否选中目标 EVT 设备；设备是否被其他手机占用扫描允许非空名称设备，连接仍校验 GATT；核对目标再重试。
认证失败 / 持续等待当前安全码、绑定还是认证、首次绑定按键确认核对编码与设备当前码；首次绑定在 60 秒内按设备键，不使用文档示例当通用码。
开始 / 继续录音按钮不可用认证权限、允许设备录音、隐私状态、命令执行中先满足前提；退出设备隐私模式，再刷新确认。
点击后提示失败，但设备已经动作可能是控制响应丢失不要反复点击开始；先“刷新状态”，读取设备的真实录音状态。
结束录音后没有新文件设备是否停止并完成封装、文件列表是否刷新等待设备封装后刷新；用设备日志核对文件生成。
下载中断 / 进度卡住连接状态、认证是否失效、文件是否改变重连认证后再点同一文件保存；收集 App 和固件同时间段日志。
手机删除后不能播放本地文件是否存在返回设备文件页重新保存；当前页面会校验并清除失效的已保存标记。
总时长未知 / 进度条不可拖动音频封装是否完整、当前平台是否支持格式不要将未知时长当 0 秒录音；核对原文件，iOS 不支持本构建的 OGG 播放。
检查显示不可验证 / 证据不足是否存在该场景所需事件或测量值按缺失项补证据或保存人工观察，不能把“已保存”当作“通过”。
无法解绑是否还有设备文件、正在录音、同步未空闲先满足解绑条件；只下载不会删除设备文件。
公共目录找不到日志是否为 Debug 构建、导出提示路径、旧 Android 存储权限按提示路径找文件；Android 10+ 后缀为 .log.txt，旧日志可能仍有按日重名副本。
当前 EVT 功能范围：BLE 发现与连接、6 字节认证与绑定、设备状态与配置、设备录音控制、文件下载及续传、本地播放与管理、日志及检查记录。没有手机麦克风录音、账户 / 云端上传、AI 转写、实时音频流、OTA 或设备文件归档。
