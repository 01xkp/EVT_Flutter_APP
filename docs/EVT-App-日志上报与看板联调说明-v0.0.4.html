EVT App 日志上报与看板联调说明

版本 0.0.4+5。此页说明当前 Debug App 中“上传日志”的实际入口、点击后的预期效果、脱敏边界和日志看板对接方式。页面中的手机界面为预期状态示意，不代表已完成真机服务器上传。

日志上报只由用户手动触发，只上传当前 App 私有日志生成的脱敏快照。不会自动后台上传，不读取公共下载目录，不上传 raw_packet_hex 中的原始蓝牙字节。

数据链路

1. 实时日志用户进入设备详情的“实时日志”。
→
2. 脱敏快照移除原始协议字节和敏感字段。
→
3. SFTP 上传固定主机指纹，先写 .part。
→
4. 完成文件同目录原子改名为 .log。
→
5. 看板读取服务端解析并经 HTTPS 提供给 Vue 看板。

联调配置和权限

  • 当前 App 直连 SFTP 只限受控 Debug 包。构建参数中的主机、端口、账号、目录、主机指纹和私钥不能提交到仓库或发送到聊天记录。
  • App 上传账号只需要创建、写入、同目录改名和删除临时文件；不需要列目录或下载权限。
  • 日志接入服务或看板后端使用独立的读取账号，并通过 HTTPS 给浏览器提供列表、详情和下载接口。
  • 真实端到端联调前，服务器需要提供专用账号、公钥授权、主机 SHA-256 指纹、上传目录、网络可达性和 20 MiB 文件限制确认。
