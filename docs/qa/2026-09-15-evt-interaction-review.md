# EVT 联调交互与页面职责

版本：0.0.3+4。本次结合《飞书20260915-162549.mp4》检查并优化现有 EVT 页面，包含此前安全码输入和播放进度修复。目标是中文入口清楚、录音操作前置、下载后直接播放、状态来源准确。

## 页面应该做什么

| 页面 | 操作与展示 | 数据来源与边界 |
| --- | --- | --- |
| 首页 | 当前设备、连接和录音状态；直达设备文件、已保存录音、实时日志、设置 | 当前连接会话；未认证时文件入口先进入设备认证。手机内录音和日志无需连接设备 |
| 连接设备 | 查找/停止查找；设备名称、信号强弱、RSSI、选中状态；选中后连接 | 实际蓝牙扫描结果，RSSI 单位 dBm；名称和信号不代表已认证 |
| 设备详情 | 连接、认证、录音状态；录音授权、开始/暂停/继续/结束；文件入口 | 会话状态、0x09 认证、0x06 录音授权、0x07 录音控制；授权关闭或隐私模式时禁止开始/继续，仍保留结束操作 |
| 设备状态区 | 电量/充电、剩余与总存储、上次读取的文件数量、隐私与同步状态、默认隐私时长；刷新状态 | 设备返回的数据；刷新改为读取当前已授权的状态、配置和文件数量，未读取不补造默认值。文件数量是上次查询结果，固件封装完成后才会出现新文件 |
| 设备信息与管理 | 设备编号、固件版本、状态采样时间；设备检查、断开、展开设备管理后解绑 | 编号和版本来自设备；解绑仍保留数据清除确认和安全码校验 |
| 设备文件 | 完整文件名、大小、文件数；保存到 App；接收字节数和百分比；本次保存成功后显示“已保存到手机”和“播放” | 0x22 文件列表、0x23 蓝牙下载。保存到手机不等于上传云端，也不代表设备文件已归档或已删除。成功标记属于当前页面的保存结果，不据文件名推断历史同步状态 |
| 已保存录音 | 手机文件名、保存时间、大小、已有时长或时长未知；播放、管理中的重命名/删除 | 本地数据库与音频文件。时间明确标注“保存于”，不是设备录音开始时间；删除只作用于手机副本 |
| 录音播放 | 真实播放状态、已播放时间、总时长、百分比、拖动；中文上一条/播放或暂停/下一条 | 本地播放器预加载并解析时长。删除装饰性波形和自行累加进度；时长未知时继续展示真实已播放时间并禁用拖动，加载失败可重试 |
| 实时日志 | 中文暂停/继续跟随、清空视图、导出；收发事件和日志保存位置 | 持久化 App 日志。暂停仅停止显示；继续立即补齐。清空视图不删除文件；导出按钮有执行中状态和失败反馈 |
| 设备检查 | 选择检查场景、查看证据/缺失项、保存验证结果、记录人工观察 | 当前快照、事件和人工记录；用于联调证据收集，不能代替实际硬件验收 |
| 检查记录 | 设备名、通过/未通过/证据不足、原因、保存时间和备注；模拟记录明确标识 | 已保存的验证结果。原“设备活动”改为明确的“检查记录”，不再只显示“已完成设备检查” |
| 设置 | 主题、手机蓝牙相关权限、连接配置状态 | 手机权限和 App 配置；不把 App 配置就绪当作真机连接或认证成功 |

## 本次修正的交互问题

- 设置、日志、文件刷新、已保存录音、播放等主要入口改为可见中文；底部导航使用文字。
- 录音授权和录音按钮集中在详情页上部；设备信息放在后面，解绑收进设备管理，消除重复电量/存储展示。
- 下载完成后可直接播放，无需返回设备页再找文件夹图标。
- 设备状态刷新此前只请求 status 权限范围，遗漏文件数量和配置；现在使用当前认证实际授予的权限集合。
- 日志暂停再继续后立即更新视图；导出失败不静默。
- 检查记录展示真实结论和原因，避免“已完成”掩盖失败或证据不足。

## 日志文件名补充

- 手动导出使用手机当前时间，精确到秒，例如 `aipin-2026-09-15-17-25-49.log`；同一秒连续导出追加 `-01`、`-02`，每次保存独立副本。
- Android Download 和 iOS Documents 接受新文件名，继续兼容旧的按日文件和轮转文件。后台按日记录与同步仍使用原有文件；内部导出副本单独保留最近 8 份，不删除公共目录中的历史导出。
- 真机发现 Android MediaStore 为 `text/plain` 自动追加 `.txt`，原查询因此不能匹配已保存的日志。Android 10+ 现在显式使用 `.log.txt`，查询与返回路径一致，避免后台同步不断生成 `(1)`、`(2)` 副本。旧的重复文件保留。
- `flutter test --no-pub test/features/device_logs`：30 项通过，包括同秒导出、并发调用、重启后的序号延续、保留策略及副本内容。
- `flutter analyze --no-pub` 无问题；Android Debug APK 构建成功。当前 Windows 环境未执行 iOS 编译。
- VER-AN10 真机已验证手动导出生成 `aipin-2026-09-15-17-27-08.log.txt`。之后补充的 MediaStore 文件名匹配修复已重新构建；最终覆盖安装返回 `INSTALL_FAILED_ABORTED: User rejected permissions`，因此该补充修复尚未在真机验证。最新版安装包为 `build/app/outputs/flutter-apk/v0.0.3-evt-easy-debug.apk`。
