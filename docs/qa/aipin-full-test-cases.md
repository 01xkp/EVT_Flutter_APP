# AIPIN 声存全量测试用例

> 基线日期：2026-08-25
>
> 适用版本：当前 `evt` 分支工作区（Flutter 包 `aipin`，Android 包名 `com.aigutta.aipin`）
>
> 目标平台：Android、iOS；Windows/Web 仅用于开发调试，不作为发布验收平台。

## 1. 测试范围与当前产品边界

本用例集以当前工程代码、已有设计文档和可见交互为准，覆盖以下闭环：首次使用、主题与品牌、手机本机录音、录音库、播放、AI 转写与总结、蓝牙扫描与硬件设备会话、观测与记录、设置和本地数据生命周期。

当前产品有三个容易混淆、需要重点回归的边界：

1. 用户界面只有一个**本机录音**入口；不应出现独立的“AI 语音”录音入口。
2. AI 处理由已保存的本机录音显式确认后触发，或在详情的“转写 / 总结”页按需触发；原始本机音频不能被移动、替换或删除。
3. 本机录音不依赖蓝牙；设备录音是独立的 EVT 功能，仅在 V1 认证有效期内通过 `0x07` 控制，不能和本机录音混淆。

> 设备 BLE 的准确接口白名单、字段和联调顺序以 `docs/app-hardware-function-list.md` 和 `docs/real-firmware-integration.md` 为准。本文件中的历史性 UI/AI 用例不扩展或替代 EVT 固件协议。

现有自动化资产：`test/` 下有 73 个 Dart 测试/支持文件、156 个 `test` 或 `testWidgets` 声明。它们是回归基础，不替代本文件列出的真机、系统设置、长时运行和外部服务验证。

## 4. 高风险探索性测试章程

| 编号 | 探索假设 | 建议操作 | 观察点 |
