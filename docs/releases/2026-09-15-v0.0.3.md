# v0.0.3 EVT 联调修复

版本：`0.0.3+4`，分支：`evt`，包名：`com.aigutta.aipin`。以 V1.6 修正版协议和 `0.0.2+3` 为基线。

## 修改内容

- 修复 Android 蓝牙权限已允许仍提示未授权：恢复与运行时授权策略一致的扫描权限配置。
- 修复正常解绑被自身权限门禁拦截；解绑期间业务权限仍撤销，断连后解绑许可失效。
- 非法安全码先校验，避免未发出的解绑操作被错误标记为待恢复。
- 取消排队中的文件下载后不再发送 `0x23`；响应通道关闭时及时终止请求。
- 修复音频分片中的 `ED` 字节被误识别为独立帧；限制响应长度，超时同时清理命令层和对应特征的会话层半帧，避免状态查询重试仍被旧数据阻塞。
- 文件下载期间禁用其他下载和刷新，退出文件页后停止继续分页。

## 联调范围

检查扫描、连接、GATT/CCCD、MTU、六字节认证/绑定/解绑、状态和录音控制、文件列表/下载/续传、断线恢复。当前 EVT 开放 `0x01/02/05/06/07/09/11/21/22/23`；HTTPS 取码、实时音频、归档及 OTA 不在本构建范围内。

详细核对及回归证据见 [EVT V1.6 联调代码审查](../qa/2026-09-15-evt-v1.6-integration-audit.md)。
