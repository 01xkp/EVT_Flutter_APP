# 总结富文本与文档命名设计

## 目标

在不改变本机录音详情页结构的前提下，扩展 AI 总结的移动端 Markdown 编辑能力，并允许用户分别为转写和总结设置可长期保留的文档名称。导出时优先使用用户设置的名称。

## 范围

- 保持录音详情页的 AppBar、播放/转写/总结三个 Tab、编辑/查看切换、保存和底部复制/导出入口不变。
- 仅在总结处于编辑状态时显示完整的两行格式工具栏。
- 不引入富文本编辑器依赖；底层继续使用 Markdown 文本，导出继续为 `.md`。
- 不支持图片和表格。
- 转写和总结各自拥有独立的、可持久化的文档名称；不会改变录音名称或后端 AI 生成的标题。

## 编辑工具栏

编辑状态下显示固定两行工具栏，避免横向滚动和不稳定布局。

第一行：一级标题、二级标题、加粗、斜体、下划线、无序列表。

第二行：有序列表、待办项、引用、分割线、链接。

格式行为：

- 标题、无序列表、有序列表、待办项与引用对当前行生效；同一按钮再次点击取消该格式，标题级别切换时替换已有标题标记。
- 加粗、斜体、下划线作用于选中文本；未选中时插入可直接替换的占位文本。
- 下划线使用 Markdown 可兼容的内嵌 HTML 标记，并由本地预览安全渲染。
- 分割线在当前段落后插入 Markdown 水平分割线。
- 链接打开轻量输入弹窗，用户填写 URL；选中文本作为链接标题，未选中时可填写标题。保存内容为标准 Markdown 链接。
- 预览器新增对应的标题、行内格式、三种列表、引用、分割线与链接样式；未知 Markdown 保持原文显示，不丢失用户内容。

## 文档名称

在转写和总结各自的标题行中增加重命名图标。点击后打开与既有重命名一致的输入弹窗。

- 输入内容是文件基础名，最大长度为 60 个字符，不输入扩展名。
- 转写与总结名称分别保存为 `transcriptTitle` 与 `summaryTitle`，空值表示未自定义。
- 自定义名称仅属于本地研究记录，不修改录音名称，也不会发送到 ASR 或总结接口。
- 导出时自定义名称优先：转写自动追加 `.txt`，总结自动追加 `.md`。
- 未设置自定义名称时，继续使用当前 `yyyyMMdd_HHmmss_转写.txt` 与 `yyyyMMdd_HHmmss_总结.md` 规则。
- 输入和导出前均剔除或拒绝 Windows、Android 与 iOS 文件名不允许的路径和保留字符，空结果回退至时间命名。
- 重生成转写或总结不会修改用户设置的文档名称。

## 架构与数据

- `ResearchCapture` 新增两个可空的独立名称字段与无副作用的更新方法。
- Drift 表和数据映射新增对应列，迁移时为已有记录写入空值，确保旧数据可读。
- `ResearchCaptureLibraryController` 负责校验、保存名称和记录用户编辑行为。
- `ResearchMarkdownDocumentEditor` 仅负责编辑与预览 Markdown；重命名入口通过现有详情页和文档内容面板回调接入，不让编辑器依赖数据层。
- 详情页依据文档类型解析展示名与导出文件名，文件扩展名始终由文档类型决定。

## 失败处理

- 重命名取消、空白输入或仅包含非法字符时不覆盖既有名称。
- 本地保存失败时保留当前页面内容并以现有 Toast 提示失败。
- 链接地址为空或格式不合法时，不插入链接；不会让预览器抛出异常。

## 验收与测试

- 每个格式按钮的插入和取消行为都有 Widget 测试。
- 预览覆盖新增 Markdown 格式、旧纯文本和未知语法保留。
- 链接输入、确认和取消具有 Widget 测试。
- 独立名称的保存、清空、重生成保留及导出优先级具有应用层或 Widget 测试。
- 迁移测试覆盖已有研究记录升级后名称为空且可正常读写。
- 运行受影响的研究模块、详情页与应用层测试，并执行 `flutter analyze`。
